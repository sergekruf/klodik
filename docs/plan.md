# Клодик — план реализации

Дизайн: [docs/superpowers/specs/2026-10-27-claude-pet-design.md](superpowers/specs/2026-10-27-claude-pet-design.md). План опирается на него. Ограничения по нагрузке и анти-цели оттуда действуют на каждом шаге.

## Устройство проекта

Swift Package, сборка `swift build`, тесты `swift test`. Скрипт упаковывает сборку в `Klodik.app` (`LSUIElement`, без иконки в Dock).

```
Package.swift
Sources/KlodikCore/          — логика без UI, вся покрыта тестами
  SessionFile.swift          — разбор файла сессии приложения → SessionInfo
  SessionStore.swift         — чтение папки сессий + слежение через FSEvents
  HookEvent.swift            — разбор событий хуков (JSON из Claude Code)
  EventServer.swift          — HTTP-приёмник на 127.0.0.1 (Network.framework)
  Tracker.swift              — правила состояний: серая / синяя / «напомнить» / работает
  AttentionPolicy.swift      — настроение Клодика и частота прыжков
  HookInstaller.swift        — дописать / удалить хуки в ~/.claude/settings.json
  AppState.swift             — state.json: позиция, метки, скрытые, настройки
Sources/Klodik/              — приложение (AppKit + SwiftUI)
  App.swift, PetPanel.swift, Sprites.swift, Animator.swift,
  SessionListView.swift, Bubble.swift, Menus.swift, FrontAppWatcher.swift
Tests/KlodikCoreTests/       — тесты + фикстуры файлов сессий и settings.json
scripts/build-app.sh         — сборка Klodik.app в build/
```

Порт по умолчанию 47821, его можно поменять в настройках. Если порт занят, Клодик предлагает другой и переставляет хуки.

## Шаги

### 0. Разведка (до кода, ~30 мин)
Хуки ставим только в тестовую папку (`.claude/settings.local.json`), глобальные настройки не трогаем.
- [ ] HTTP-хук на выключенный порт: сессия не тормозит, ошибок пользователю не видно. Если это не так — фиксируем запасной вариант: `async` command-хук с `curl`.
- [ ] Срабатывает ли `Notification` (`permission_prompt`) в сессии вкладки Code в режиме «спрашивать разрешения».
- [ ] Через сколько секунд после открытия сессии меняется `lastFocusedAt` в её файле. Меняется ли он, если ход закончился, пока сессия открыта на экране.
- [ ] Записать выводы в дизайн-документ, раздел «Проверено».

**Готово, когда** на все три вопроса есть ответ и под каждый выбран вариант реализации.

### 1. Каркас и окно (~1 ч)
- [ ] `git init`, `.gitignore`, Package.swift с тремя таргетами.
- [ ] Прозрачная `NSPanel` поверх всех окон и на всех рабочих столах, без рамки, со статичным Клодиком; перетаскивание и запоминание позиции; меню «Выйти».
- [ ] `scripts/build-app.sh` собирает `build/Klodik.app`.

**Готово, когда** Клодик висит в углу, его можно перетащить, после перезапуска он на том же месте, иконки в Dock нет. Если позиция оказалась за пределами экранов (отключили монитор), он возвращается в угол.

### 2. Спрайты и анимации (~1,5 ч)
- [ ] Пиксельная сетка талисмана, рисуется кодом без сглаживания, ~48×48 точек.
- [ ] Анимации: дышит/моргает, работает, машет, прыгает, радуется, спит. 6–8 кадров, 8–12 кадров в секунду.
- [ ] Аниматор на таймере. Во сне таймер останавливается полностью.

**Готово, когда** все анимации переключаются из отладочного меню. В покое `top` показывает меньше 0,5% CPU, память меньше 40 МБ.

### 3. Файлы сессий (~1 ч, TDD)
- [ ] `SessionInfo`: `localId`, `cliSessionId`, `title`, `projectName`, `isArchived`, `lastFocusedAt`, `lastTurnEdgeAt`, `lastActivityAt`, `statusCategory`, `statusDetail`.
- [ ] Тесты на фикстурах: обычный файл; без `cliSessionId`; без `postTurnSummary`; битый JSON; файл `deleted_*` — пропускается.
- [ ] `SessionStore`: первичное чтение плюс FSEvents, перечитывать только изменённые файлы. Нет папки или формат сломан — флаг `formatBroken`, без падения.

**Готово, когда** тесты зелёные и по реальной папке строится список из 389 сессий (586 файлов с копиями) быстрее чем за секунду.

### 4. Приём событий хуков (~1 ч, TDD)
- [ ] `HookEvent`: `sessionId`, `kind` (`promptSubmit` / `preTool` / `postTool` / `notification(type)` / `stop` / `stopFailure` / `sessionEnd`), `at`.
- [ ] Тесты разбора на примерах JSON из документации, неизвестные поля и события игнорируются.
- [ ] `EventServer`: `POST /event` только на `127.0.0.1`, ответ сразу, тело больше 64 КБ отклоняется.

**Готово, когда** `curl -d @fixture.json localhost:47821/event` доходит до трекера (видно в отладочном логе).

### 5. Правила состояний (~2 ч, TDD — главный шаг)
`Tracker` сводит файлы, события и метки пользователя в список `[Item]`: точка (`gray` / `blue` / `remind`), `waitingSince`, `openedSinceWaiting`, плюс множество работающих сессий. Тест на каждое правило:
- [ ] серая из хука (`permission_prompt`, `elicitation_dialog`, `agent_needs_input`) и из файла (`blocked`);
- [ ] серая снимается после `promptSubmit`, `postTool` после разрешения или нового хода не `blocked`;
- [ ] открытая серая (`lastFocusedAt > waitingSince`) остаётся в списке с `openedSinceWaiting = true`;
- [ ] синяя: `lastTurnEdgeAt > lastFocusedAt`, итог не `blocked`; снимается после открытия;
- [ ] «напомнить» держится до первого открытия после метки, снимается вручную;
- [ ] «скрыть до следующей активности» — до нового `lastTurnEdgeAt`;
- [ ] окно 7 дней и архивные сессии;
- [ ] события от сессий без файла (терминал, VS Code) игнорируются;
- [ ] пропущенный `stop`: «работает» гаснет само через 10 минут без событий.

**Готово, когда** все тесты зелёные. Прогон по реальной папке даёт примерно 16 серых (11 из них открытых) и 6 синих — цифры из проверки дизайна.

### 6. Политика внимания (~1 ч, TDD)
`AttentionPolicy.mood(items, working, now, claudeFrontmost, snoozedUntil) -> Mood`, где `Mood` — `sleep` / `idle` / `working` / `badgeOnly` / `waveSometimes` / `jump(interval)`. Тесты:
- [ ] неоткрытая серая ждёт меньше 2 мин → прыжок раз в 60 с; 2–10 мин → раз в 30 с; больше 10 мин → постоянно;
- [ ] только открытые серые и синие → изредка машет;
- [ ] Claude на переднем плане или «отложено» → только бейдж;
- [ ] пусто и 15 минут без событий → спит.

**Готово, когда** тесты зелёные.

### 7. Список, бейдж, пузыри (~2 ч)
- [ ] Бейдж с числом над Клодиком.
- [ ] Всплывающий список (SwiftUI) по клику: точка, название, проект, «12 мин». Сортировка: серые, потом синие, старые сверху. Закрывается кликом мимо или Esc.
- [ ] Клик по строке → `open claude://code/continue?session=<localId>`.
- [ ] Правый клик по строке: «Напомнить» / «Не напоминать», «Скрыть до следующей активности».
- [ ] Правый клик по Клодику: «Отложить на 30 минут», «Настройки», «Выйти».
- [ ] Пузырь с названием сессии на 3 с при новом событии, кроме случая, когда Claude на переднем плане (`FrontAppWatcher` через `NSWorkspace`).
- [ ] Связать `Tracker` → `AttentionPolicy` → `Animator`.

**Готово, когда** на живых сессиях всё работает руками: клик открывает нужную сессию, метки работают, после того как все сессии закрыты, Клодик успокаивается.

### 8. Установка хуков (~1 ч, TDD)
- [ ] `HookInstaller.install(settingsURL:port:)` и `uninstall(settingsURL:)`. Перед записью копия `settings.json.klodik-backup`. Хуки Клодика помечены, чужие хуки сохраняются.
- [ ] Тесты: пустой файл; файл с хуком `SessionStart` пользователя; повторная установка не дублирует; удаление убирает только свои; битый JSON → ошибка без записи.
- [ ] Пункты меню «Установить хуки» / «Удалить хуки».

**Готово, когда** тесты зелёные и после установки в реальном `~/.claude/settings.json` хук `hub-context.sh` на месте.

### 9. Настройки и автозапуск (~45 мин)
- [ ] `AppState` в `~/Library/Application Support/Klodik/state.json`. Битый файл → значения по умолчанию.
- [ ] Окно настроек: автозапуск при входе (`SMAppService`), окно в днях, шкала напоминаний, порт, хуки.

**Готово, когда** настройки переживают перезапуск, а автозапуск включается и выключается.

### 10. Приёмка (~30 мин)
- [ ] Полдня реальной работы с Клодиком.
- [ ] Замер нагрузки в покое и при прыжках (`top -pid`): CPU и память в пределах дизайна.
- [ ] «Удалить хуки» и выход: `settings.json` вернулся к исходному виду.

## Где вероятнее всего сломается

1. Приложение Claude поменяло формат файлов сессий → Клодик живёт только на хуках и предупреждает в меню (шаги 3 и 5).
2. Порт занят другим приложением → подсказать другой порт, а не молча не работать (шаги 4 и 8).
3. В `settings.json` уже есть хуки или он битый → чужое не трогать, при ошибке ничего не записывать (шаг 8).
4. Монитор отключили, Клодик остался за экраном → вернуть в угол (шаг 1).
5. Тысячи событий подряд, когда Claude быстро гоняет инструменты → без лагов и роста памяти: события только обновляют состояние, перерисовка не чаще кадра анимации (шаги 4 и 5).

Итого примерно 12 часов работы.

## Итоги приёмки (2026-10-28)

Проверено:
- 107 тестов зелёные.
- Нагрузка установленной копии (`~/Applications/Klodik.app`): в покое 0,23% CPU и 13 МБ. 3000 событий хуков за 0,8 с (0,27 мс на ответ) стоили 1 с процессорного времени, память после них — 35 МБ.
- Утечек нет (`leaks`). Раздутая куча после запуска (44 МБ) была из-за чтения 29 МБ файлов сессий без `autoreleasepool`, исправлено: теперь 14 МБ.
- «Удалить хуки» возвращает `~/.claude/settings.json` к исходному содержимому (совпадает с `settings.json.klodik-backup`), хуки поставлены обратно.
- Автозапуск при входе включён.

Осталось проверить руками:
- Клик по Клодику, открытие сессии из списка, правый клик по строке, переключатели в окне настроек.
- Запрос разрешения в десктопе показывается как обычно при установленных хуках.
- Полдня работы с Клодиком: не прыгает ли без причины и успокаивается ли, когда всё закрыто.

Шпаргалка:
- `bash scripts/build-app.sh --install` — собрать, положить в `~/Applications` и перезапустить.
- `Klodik --sessions` — список так, как его видит Клодик.
- `Klodik --install-hooks` / `--uninstall-hooks`, `Klodik --login-item status|on|off`.
- `KLODIK_DEBUG=1` — события хуков в журнал, `KLODIK_DEMO=<анимация>` — крутить анимацию, `--sheet файл.png` — все кадры на одном листе.
